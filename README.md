# Rust Server Owner F1 Commands

> Open with **F1** and paste any command into the console.

---

## 🎨 Creative Mode

# Enable Creative for everyone
creative.allusers true

# Free building (no resources required)
creative.freebuild true

# Unlimited resources
creative.unlimitedresources true

# Unlimited electricity / IO
creative.unlimitedio true

# Instant crafting
craft.instant true

# God mode
god

# Fly
noclip

# Disable stability
build.nostability true

# Disable decay
decay.scale 0

---

## ❌ Disable Creative

creative.allusers false
creative.freebuild false
creative.unlimitedresources false
creative.unlimitedio false
craft.instant false
god
noclip
build.nostability false
decay.scale 1

---

env.time 6
